
# The Gentle Pour

*A cozy, interactive café website inspired by my experience as a barista.*

## Project Overview

The Gentle Pour is a café-themed website created to practice front-end development and JavaScript functionality. The goal was to create a warm, welcoming space where visitors could browse drinks, interact with the website, and submit feedback.

## Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layouts, and visual design
- **JavaScript** — Interactive features and form validation
- **Figma** — Wireframing and layout planning
- **Canva** — Branding, logo, favicon, and photo editing

## Key Features

- **Product Display:** Showcases café drinks and products.
- **Light/Dark Mode:** Allows visitors to change the website's appearance.
- **Contact Form Validation:** Checks user input before submission.
- **Interactive Elements:** JavaScript-powered features that encourage user engagement.
- **Custom Branding:** Original café logo, favicon, and edited drink photography.

## Development Process

I began by outlining the website's goals and JavaScript requirements. I gathered visual references and created a medium-fidelity wireframe in Figma to plan the layout and content hierarchy.

Using Canva, I developed the color palette, logo, favicon, and edited photographs of drinks I had made while working as a barista.

I then built the website using HTML, CSS, and JavaScript, focusing on consistent styling, navigation, and interactive functionality.

## Challenges & Outcomes

One of my goals was to balance the café's visual design with its required JavaScript features. This meant making sure the interactive elements felt like part of the website rather than separate assignments.

The finished website includes a product display, light/dark mode, form validation, and interactive elements. It gave me more practice combining design decisions with front-end functionality.
